⛈ StormGuard

A zero-training situational awareness tool for emergency responders facing inland flooding. It answers three questions in under 10 seconds: Where is flooding? How bad? Getting worse?

How it works

Every API call is made directly from this browser to free federal endpoints — no backend, no database, no hosting cost. Readings are synthesized into one color-coded map plus a plain-language action panel, so a responder never has to interpret raw numbers.

Known limitations

No official federal real-time power-outage API exists — this is a documented data gap, not an oversight. Census population impact uses real tract boundaries and real point-in-polygon geometry, but the actual population counts require a free Census API key (VITE_CENSUS_API_KEY) that isn't bundled with this build — without one, the Population panel says so explicitly rather than showing a silent zero. Enable Test Scenario to see the full intended experience with fixture data regardless.

LiDAR/scanning-radar river-stage sensors exist (e.g. NOAA's ANCHOR project, ~14 sites nationwide) but are not aggregated into a public, free, national real-time API the way USGS stage data is — so they aren't a source we can integrate today. Note that some USGS streamgages already use non-contact radar/LiDAR instruments instead of traditional floats; that data reaches this app unchanged through the same USGS Instantaneous Values feed above, since the API doesn't distinguish sensor technology.

Gauge severity colors (major/moderate/minor/normal) use fixed absolute stage-height thresholds, not each gauge's real local flood stage — a river's actual flood category depends on its own datum, so the same reading in feet means something different on different rivers. These thresholds are calibrated for the default Louisiana / lower-Mississippi area shown above; treat severity colors as approximate for gauges elsewhere.

NWS forecast points (◆ diamond markers) use NWS's own authoritative flood category and an actual forecast crest, unlike the USGS gauges' approximate colors above. Coverage is 13 individually-verified forecast points across the Mississippi, Pearl, Atchafalaya, Red, and Calcasieu rivers — a curated set for this AOI, not the full national AHPS network, since the underlying API's own region-search doesn't reliably filter by area.

The region picker (top bar) re-scopes USGS gauges, NWS alerts, and Census population to the selected state — all fetched fresh from real federal data, not a demo-only switch. Two things stay Louisiana-specific regardless of the picker: NWS forecast points (the 13-point curated set above) and any AOI spanning more than one state — Census/TIGERweb queries are inherently per-state, so a multi-state region only gets population data for its primary state.

StormGuard - Flood Situational Awareness for Emergency Responders
IEEE Response Quest Challenge 2026 - Phase 3 submission

StormGuard is a browser-based flood situational-awareness tool for emergency responders. It combines live USGS river gauges, NWS alerts and river-crest forecasts, NHC hurricane tracks, NEXRAD radar, FEMA flood zones, Census population and OpenStreetMap hospitals on one map, and ranks what needs attention as Respond now / Prepare / Monitor. Each warning shows people in the area, age 65+, homes without a vehicle and hospitals inside it. Sources fail independently and show the last good data when one is down. A built-in test scenario injects data when no disaster is active. Data sources (with endpoints) and algorithm descriptions are in the repository README and docs/ALGORITHMS.md. Known limits: no evacuation orders, no satellite imagery, and population figures are upper-bound estimates.
